# Code signing policy

Frigicom does not publish releases yet; this describes the release pipeline inherited from upstream halloy, which signs on the fork's behalf only once the SignPath credentials are configured for it.

Windows release builds of Frigicom are code-signed, including the Windows installer itself and the Frigicom application binary packaged inside the installer.

Free code signing provided by [SignPath.io](https://signpath.io/), certificate by [SignPath Foundation](https://signpath.org/?utm_source=foundation&utm_medium=github&utm_campaign=gitextension).
