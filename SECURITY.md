# Security Policy

## Supported Versions

Frigicom is pre-alpha and has published no releases. Only `main` is
supported; once releases start, only the latest one will be.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please DO NOT disclose it publicly until we’ve had a chance to fix it.

Please don’t report security vulnerabilities via GitHub issues, instead report them privately via the [Security Advisories](https://github.com/doomcrack/halloy/security/advisories/new) page.

Vulnerabilities in the chrome that also reproduce on upstream [halloy](https://github.com/squidowl/halloy/security/advisories/new) should be reported there as well.
