# URL Schemes

Frigicom registers a URL scheme for importing themes:
`frigicom:///theme?e=base64EncodedThemeData`.

The `halloy://` scheme is accepted as well, so links from halloy's theme gallery
keep working — the theme format is unchanged from upstream. A list of community
created themes can be found at <https://themes.halloy.chat/>.

::: info
The IRC-era `irc://` and `ircs://` schemes are gone; there are no servers to
connect to.
:::
